# Flutter Mobile App

Mobile portfolio companion for **Ilyas Hassan Mohamed**.

## Stack

- Flutter + Dart
- Material 3 dark theme
- Matches web portfolio branding

## Run

```bash
cd app
flutter pub get
flutter run
```

## Structure

This folder is the **mobile** part of the monorepo:

```
profile_ilyas/
├── frontend/   → React web portfolio
├── backend/    → Node.js + MongoDB API
└── app/        → Flutter mobile app (this folder)
```
